# Zomato-Orders-Dashboard

This project is a Power BI dashboard built on Zomato order data.  
It provides a comprehensive view of food delivery operations, customer activity, and hotel performance.

## Features
- 📊 Summary metrics: total orders, average order value, min/max orders
- 🍕 Top 5 food items ordered
- 🏨 Hotel sales and performance comparisons
- 💳 Payment method distribution (Card, UPI, COD)
- 🚚 Delivery status breakdown (Delivered, Cancelled, In Progress)
- 👥 Top customers and order counts
- 📈 Sales trends over time

## Purpose
- Practice Power BI dashboard design and storytelling
- Showcase data visualization skills for analytics interviews
- Explore business insights from food delivery datasets

## Files
- `Zomato_Orders_Dashboard.pbix` → Power BI dashboard file
- `Zomato_Orders_Dashboard.pdf` → Exported dashboard view

## Insights
- Identify best‑performing hotels by sales
- Track delivery success vs cancellations
- Discover customer ordering patterns
- Highlight popular food items driving revenue
